# L04: direct numeric inference

Predict expected spike counts per20ms bin for one recorded hippocampal place cell from [position_cm,velocity_cm_per_second]. The64 fixed uniformly spaced training examples provide noisy observed counts, not expected rates. Return value [nonnegative expected count], not sampled integer spikes. Each test row is a separate prediction. No trial time or held-out spike history is supplied. Pretrained weights remain fixed; only in-context calibration is permitted.

[Input manifest](input-manifest.json) freezes every retained test case, input hash, output layout and units. No test targets are read during preparation. Exactly64 labeled training examples, selected by uniform training-index spacing without examining outcomes, are supplied in context. No external fitted model or model-written code is used. Primary score: `bits_per_spike_train_mean` (higher is better). This is an explicitly custom protocol, not a published official benchmark replication. This is the separate in_context_calibration condition. All reasoning models use low effort. The task-specific reference uses all training bins, so the comparison does not equalize training information.
